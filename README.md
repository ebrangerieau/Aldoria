# Les Chroniques d'Aldoria

Jeu d'aventure 2.5D jouable dans le navigateur, où chaque combat et chaque énigme repose sur une notion du programme de maths (6ème et seconde). Projet familial, sans publicité ni collecte de données hors du foyer.
